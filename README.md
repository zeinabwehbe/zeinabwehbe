## Master's thesis

**Scalable Opinion-Oriented Video Search Using Transcript-Based Semantic Retrieval**

A two-stage retrieval pipeline that routes each question to the right video using LLM-generated topic summaries, then searches its timestamped transcript chunks. I evaluated it on 26 Arabic speeches with 374 annotated questions.

- Reached 94.92% RoutingRecall@5
- Raised Hit@5 from 72.99% to 77.81% (p = 0.006) while searching 8.5× fewer chunks
- Written up as an IEEE-format paper

`Python` `Whisper` `pyannote.audio` `PostgreSQL` `pgvector` `Qwen`
